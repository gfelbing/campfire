## Notes

- Latency = glass-to-glass on one host (shared `Instant` clock, send-stamp in payload); the Lite02 wire carries no frame timestamp.
- `max-gap` = largest gap in send-stamp space (missing frames); `max-stall` = largest gap in receive time between consecutive frames in send order (what a consumer presents as a freeze).
- Loss scenarios: netem on `lo` egress in a private netns, `delay 100ms 30ms distribution normal` (+ loss %); both directions.
- Per-direction and SFU CPU are informational only (README §6), not gating.
- G2 is the Tier-1 gate; G1 (codecs) and G3 (audio underrun) need the Tier-2 headless-browser run.
